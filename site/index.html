The problem

  
Memory for agents means infrastructure. For what is basically a notes file.

  

    

      
Managed memory

      
Server or cloud account. API keys. Your agent's memories on someone else's disk. A bill, forever.

      
your data leaves the box

    

    

      
Vector DBs

      
Docker, embeddings pipeline, ops work — to remember 10k facts like "user prefers Python".

      
overkill for facts

    

    

      
Prompt stuffing

      
Jamming chat history into the prompt until it gets slow, expensive, and breaks at scale.

      
dumb + pricey

    

  







  
Our solution

  
Patch once. Every call remembers.

  

    

      
from memolite import MemoryStore, patch_openai

store = MemoryStore("agent.db")
patch_openai(client, store, session="s1")
# done. every call now auto-recalls + auto-stores.

      
# system-wide: every Python on this box
$ memolite autoinstall --db agent.db
$ MEMOLITE_OFF=1 python app.py  # kill-switch

      
# LLMs as embedders, one line each
Config(embedder=openai_embedder(client))
# or local_embedder() / ollama_embedder() — offline

    

    

      
    
        
  • Shared brain — GPT writes a fact, Claude recalls it verbatim. Sessions isolate, global is shared.
    • 
        
  • Hardened — AES-256-GCM at rest, PII redacted pre-write, SHA256 WORM chain + verify, per-session readers/writers, 0600 perms.
    • 
        
  • Hybrid recall — FTS5 + vector rerank. Bring SOTA embeddings or use the zero-dep baseline.
    • 
        
  • Fleet sync — memolite sync a.db b.db merges nodes with last-write-wins.
    • 
        
  • Honest evals — keyword recall@3 0.6, paraphrase 0.2 with stdlib embed. Harness ships in repo.
    • 
      

      
no daemon, no spyware — fail-open, memory errors never break your LLM call
